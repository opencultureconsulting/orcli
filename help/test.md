# orcli test

```
orcli test - run functional tests on tmp OpenRefine workspace

Usage:
  orcli test [OPTIONS]
  orcli test --help | -h

Options:
  --port PORT
    PORT on which OpenRefine should listen
    Default: 3333

  --timeout SECONDS
    maximum seconds to wait for OpenRefine to start
    Default: 60

  --help, -h
    Show this help

```
